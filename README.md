# Urban-Lunch-Android-App-Testing-Project

Projeto de Quality Assurance (QA) realizado durante minha formação em testes de software, com foco nos testes funcionais do aplicativo Android Urban Lunch.

O aplicativo permite que clientes escolham um restaurante e um ponto de coleta, selecionem um ou mais pratos e confirmem o pedido. O objetivo do projeto foi analisar os requisitos, preparar um checklist e testar o aplicativo em um emulador.

## 🎯 Objetivos do Projeto

Analisar os requisitos e os layouts do aplicativo Urban Lunch.

Criar um checklist com base nos requisitos destacados para teste.

Instalar o aplicativo em um emulador Android com o dispositivo Pixel 5.

Validar o fluxo de seleção de restaurante, escolha de pratos e confirmação do pedido.

Registrar os resultados dos testes e reportar bugs encontrados.

## 📱 Testes Android

### Fluxo do aplicativo:

Selecionar um restaurante e um ponto de coleta.

Escolher um ou mais pratos.

Confirmar o pedido.

### Atividades realizadas:

Análise dos requisitos do Urban Lunch.

Consulta dos layouts da aplicação no Figma.

Criação de um checklist de testes com base nos requisitos indicados.

Instalação do aplicativo em um emulador Pixel 5.

Execução das verificações no aplicativo.

Registro dos resultados como APROVADO ou REPROVADO.

Criação de relatórios de bug no Jira para os testes reprovados.

Associação dos links dos relatórios de bug aos itens correspondentes no checklist.
